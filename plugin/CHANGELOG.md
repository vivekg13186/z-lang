# Changelog

## 0.1.0 — initial release

- Language registration for `.z` files
- TextMate grammar covering comments, strings, numbers, booleans, null, special forms, builtins, and operators
- Bracket matching and auto-closing for `()`, `[]`, `{}`, and `"`
- Snippets for common forms: `fn`, `lambda`, `if`, `while`, `for`, `do`, `set`, `try`, `obj`, `arr`, `map`, `filter`, `reduce`, JSON, `run`
